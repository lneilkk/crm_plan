# 개발 Task (Claude Code)

MVP는 12개 단계(M0~M11), 53개 Task로 나눈다. Task 하나는 Claude Code 한 세션에서 끝낼 수 있는 크기이고, 각각 '완료 기준'을 테스트로 확인할 수 있게 적었다.

- 진행 현황은 [CHECKLIST.md](CHECKLIST.md)에 표시한다.
- 기획서는 [Proposal.md](Proposal.md)다.

## 진행 방식: 프로토타입 먼저, 피드백으로 보완

전체 화면이 돌아가는 프로토타입을 먼저 만들어 직원 피드백을 받고, 그 뒤에 보안과 인프라를 갖춘다. 아래 Task 표는 기능별로 묶여 있으므로, 실제 진행은 이 라운드 순서를 따른다.

| 라운드 | 목표 | 포함 Task | 데이터 |
| --- | --- | --- | --- |
| R1. 프로토타입 | 예약 → 내원 처리 → 통계가 한 번에 돌아가는 화면을 직원이 직접 써 보기 | M0 전체, T1-1, T1-2, T1-4, T2-1, T2-4, T3-1, T3-2, T4-1, T4-2, T5-1~T5-3, T7-1, T7-2, T10-1 | 가짜 데이터만 |
| R2. 피드백 반영 | 화면·흐름을 고치고 나머지 기능 추가. 피드백마다 짧게 반복 | T4-3, T4-4, T5-4~T5-6, M6, T7-3, 피드백으로 생긴 새 Task | 가짜 데이터만 |
| R3. 보안 게이트 | 실제 환자 데이터를 올릴 수 있는 상태로 만들기 | T1-3, T2-2, T2-3, T2-5, T3-3, T3-4, M8 전체, T10-2~T10-6, T11-2 | 가짜 데이터만 |
| R4. 이관·오픈 | 기존 데이터 이관, 병행 운영, 오픈 | M9 전체, T11-1, T11-3, T11-4 | 실제 데이터 |

- **프로토타입 서버**: R1~R2는 AWS가 아닌 외부 서버에 Docker Compose로 올리고, R3에서 같은 구성 파일로 AWS에 옮긴다. 외부 서버에서도 가짜 데이터만 쓰고, 로그인과 IP 제한으로 접속을 막는다.
- R3를 통과하기 전에는 실제 환자 데이터를 어떤 환경에도 넣지 않는다. 프로토타입이 잘 돌아가도 예외를 두지 않는다.
- **처음부터 지키는 것**: 데이터 구조(T1-1), 암호화 컬럼(T1-2), 권한 검사 구조(T2-4)는 나중에 바꾸면 전부 다시 만들어야 하므로 R1에 포함했다. 프로토타입에서 줄이는 것은 화면 완성도와 인프라이지, 구조가 아니다.
- **피드백 기록**: 피드백은 docs/FEEDBACK.md에 날짜·요청자·내용으로 적고, 반영할 것만 Task ID(예: F-1)를 붙여 TASKS.md에 추가한다.

## 작업 원칙

- **순서대로 진행**: 단계 번호 순서가 의존 순서다. 한 번에 Task 하나만 지시하고, 완료 기준 통과 후 커밋한다.
- **지시 방법**: "T4-2를 진행해줘. 완료 기준을 테스트로 작성하고 통과시켜줘"처럼 Task ID로 지시한다. 이 탭을 Markdown으로 내보내 저장소의 docs/TASKS.md에 두면 Claude Code가 직접 읽을 수 있다.
- **CLAUDE.md에 고정 규칙 기록(T0-2)**: '절대 규칙'을 저장소 루트의 CLAUDE.md에 넣어 매 세션에 적용되게 한다.
- **테스트 우선**: 권한·상태 전환·암호화처럼 틀리면 사고가 되는 로직은 테스트를 먼저 쓴다.

## 기술 스택 (제안)

한 사람이 Claude Code로 유지보수하기 쉽도록 언어 하나, 애플리케이션 하나로 구성한다. 익숙한 스택이 있으면 바꿔도 Task 구성은 그대로 쓸 수 있다.

| 영역 | 선택 | 이유 |
| --- | --- | --- |
| 언어·프레임워크 | TypeScript, Next.js (화면 + API 한 프로젝트) | 프론트·백엔드를 한 저장소·한 배포 단위로 관리 |
| DB | PostgreSQL (AWS RDS) | 저장 암호화, 자동 백업, 행 단위 권한 제어 |
| ORM·마이그레이션 | Prisma | 스키마 변경 이력이 코드로 남음 |
| 인증 | 자체 계정 + TOTP 2단계 인증, 서버 세션 | 직원 수가 적어 외부 로그인 서비스 불필요 |
| UI | Tailwind CSS + shadcn/ui | 큰 버튼·표 중심 화면을 빠르게 구성 |
| 테스트 | Vitest(단위), Playwright(화면) | 완료 기준 자동 검증 |
| 인프라 코드 | Terraform | AWS 구성을 코드로 남겨 재현·검토 가능 |
| 실행 환경 | Docker Compose, EC2 t4g.small 1대 | 월 비용 최소. 사용자가 늘면 ECS Fargate로 이전 |
| 메시지 (2차) | 알림톡 발송 대행사 API | MVP 범위 밖 |
